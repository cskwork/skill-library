Install

# clone the library once
git clone https://github.com/cskwork/skill-library.git

# install into your app project
node skill-library/skills/stateless-mcp-builder/scripts/install-skill.mjs \
  --target claude --project /path/to/your-app

# lands in .claude/skills/stateless-mcp-builder/

The installer copies files only. It refuses overwrite, installs no packages, edits no MCP configuration, and connects no server. Skill installation, server implementation, and harness attachment stay separate steps. Or copy skills/<name>/ into your harness's skills folder by hand.

03

Why this library

evidence Proof, not claims

Every skill ends at a completion gate: run the checks, record PASS/FAIL/SKIP, mark unrun things NOT RUN. No fabricated versions, endpoints, or benchmarks.

dated Facts with timestamps

Protocol and dependency knowledge is a dated research baseline with a source register — never timeless truth. Revalidate at implementation time.

0-dep Self-contained packages

Markdown, scripts, and templates you can read in an afternoon. Node for tooling, no npm dependencies, no build step, nothing phoning home.
